## Docx export — a real Quarto bug found and worked around, worth knowing before rendering again

Quarto (1.9.37, this environment) **silently drops all `.callout-*` div content in docx output** —
confirmed with a minimal 4-line test file, so it's an environment bug, not a paper problem. Fixed
by converting all 16 real callout blocks to plain blockquotes (`> **Label:** text`), which survive
in every format. **Don't reintroduce `.callout-*` divs in this file** — use the blockquote
convention instead. Also fixed: the paper's tables used `DT::datatable()` (HTML-only, degrades to
raw text in docx — switched to plain `kable()`), and the docx had no visible title/author (Quarto
doesn't auto-render YAML title as body text for docx like it does for html) — fixed with a
`{.content-visible when-format="docx"}` block holding a manual `.unnumbered` title, docx-only.
Full writeup: `docs/pipeline_reference.md` section G.
