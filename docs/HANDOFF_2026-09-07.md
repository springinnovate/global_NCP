- **Clarified for the user, worth restating precisely in a fresh session**: CN and Kc are not the
  same *kind* of thing, and that's why only CN has a table file. CN is *assigned* per pixel from a
  static lookup (land-cover class + soil group -> one fixed number) — that's exactly what
  `gcn250_esa_lc_cn_table.csv` is. Kc for non-crop vegetation is *computed* from the Kamble et al.
  regression (Kc = 1.457×NDVI − 0.1725) applied to real NDVI imagery, which varies by pixel and by
  month — there is no fixed "Kc for forest" the way there's a fixed "CN for forest," by design, not
  by omission. **Concrete next step, not yet done**: acquire MOD13A3 NDVI (source identified,
  never downloaded) and actually run the regression to produce real Kc_1...Kc_12 rasters — that's
