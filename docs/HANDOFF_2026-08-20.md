## Immediate next task, mid-flight when tokens ran low

**User's ask, not yet done**: the 5 new per-service CNA maps (slide "Activos críticos, servicio
por servicio" / "Critical assets, service by service") currently render flat single-color
green/gray (binary critical/not-critical) — user correctly flagged this as potentially misleading
(flattens real variation, same lesson already learned and fixed for the *aggregate* CNA map
earlier this project, which uses continuous priority-rank 1-20 opacity instead of a flat fill).

**The blocker, already confirmed**: the per-service `prioritizr` solutions
(`data/external/critical_natural_assets/per_service_solutions/*.tif`) are **binary only** — per
the paper's own Extended Data Table 5 documentation, single-NCP scenarios were only solved at the
90% target, not the full 5–100% budget range that produces the aggregate raster's continuous
1–20 rank. So there is no rank data to reuse for these 5 maps the way the aggregate map does.

**The fix, scoped but not built**: use the continuous "realized" per-service magnitude layers
already downloaded (`data/external/critical_natural_assets/individual_layers/*.tif`, 10 files,
from 2026-08-19) to modulate fill opacity *within* the critical (green) cells — same visual
technique as the aggregate map, different underlying data source (magnitude of provision, not
optimization priority rank — a real, disclosable difference, not a substitute pretending to be
the same thing).

Confirmed today, useful before resuming:
- Values are **not** 0–1 despite "norm" in the filenames (checked pollination: range 0–48) — will
  need the same percentile-clip pattern already used elsewhere in this codebase (e.g.
  `make_colombia_report_maps.R`'s `quantile(vals, c(0.01, 0.99))` approach), not a naive
  0–1 assumption.
- 4 of 5 services have an unambiguous 1:1 file match: Pollination, Sediment retention (→
  `realized_sedimentdeposition_attn_500km...`), Nitrogen retention (→
  `realized_nitrogenretention_attn_500km...`), Coastal protection (→
  `realized_coastalprotection_norm...`).
- **Nature access is ambiguous**: the per-service solution "Z" is just "nature access within 1hr
  travel" with no rural/urban split, but the realized layers are split 4 ways (rural/urban ×
  60/360 min). Needs a decision before implementing — e.g., mean of `rural_60` + `urban_60`, or
  picking one variant with a disclosed caveat. Don't invent a combination silently; flag it to the
  user or note the approximation explicitly in the script/notes.

Implementation sketch: extend `scripts/mapping/make_colombia_cna_per_service_maps.R` — for each
service, also load+trim+reproject (EPSG:4326, `near` won't work for continuous data, use
`bilinear`) the matching realized layer, zonal-extract mean magnitude per grid cell (same pattern
already in the script for the binary fraction), clip to 1st/99th percentile, map to alpha within
`geom_sf(aes(fill = is_critical, alpha = magnitude))`. Re-render both languages' slide 4 after
(current image refs: `colombia_cna_5panel.png` for the combined figure — same filename can be
overwritten, or bump to a new name and update both .qmd files' image paths).
